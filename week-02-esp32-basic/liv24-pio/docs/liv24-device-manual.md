## 1. Introduction / บทนำ

**Smart Environment Monitor** คืออุปกรณ์ตรวจวัดสภาพแวดล้อมอัจฉริยะภายใต้แบรนด์ LIV24 ออกแบบสำหรับการติดตามคุณภาพอากาศ คุณภาพน้ำ และการตรวจจับน้ำรั่วในพื้นที่อาคาร ส่งข้อมูลผ่านระบบเครือข่าย Ethernet และแสดงผลบนหน้าจอสัมผัส 4.3 นิ้ว

**Key Features / คุณสมบัติหลัก**

- รองรับเซ็นเซอร์ RS485 Modbus RTU 3 รุ่น
- แสดงผลแบบ Real-time บนหน้าจอสัมผัส
- เก็บข้อมูลย้อนหลัง 24 ชั่วโมง และ 7 วัน
- เชื่อมต่อ Home Assistant ผ่าน MQTT
- แจ้งเตือนผ่าน Telegram Bot
- ตั้งค่าได้ผ่าน Web UI โดยไม่ต้องแก้ไข Firmware
- อัปโหลดโลโก้บริษัทได้ผ่าน Web Browser

## 2. Safety Precautions / ข้อควรระวังด้านความปลอดภัย

- **จ่ายไฟ DC 6–30V** ผ่านขั้วต่อ Power ด้านหลังอุปกรณ์ ห้ามใช้แรงดันต่ำกว่า 6V หรือสูงกว่า 30V
- **RS485** ต้องต่อ GND ร่วมระหว่างอุปกรณ์เสมอ ไม่เช่นนั้นอาจเกิดความเสียหายกับวงจร
- **ห้ามใช้งานในสภาพแวดล้อมที่มีน้ำ** อุปกรณ์ไม่ได้รับการป้องกันน้ำ (ไม่มี IP rating)
- **ถอดไฟก่อนต่อสาย** ทุกครั้งก่อนเปลี่ยนการเชื่อมต่อเซ็นเซอร์
- อุณหภูมิการทำงาน: 0°C ถึง 50°C

## 3. Hardware Overview / ภาพรวมฮาร์ดแวร์

### Main Controller

- **MCU:** Espressif ESP32-P4 (RISC-V Dual Core)
- **Display:** 4.3" Capacitive Touchscreen (800×480)
- **Ethernet:** 100Mbps via IP101 PHY (RJ45)
- **RS485:** Half-duplex Modbus RTU
- **Relay Output:** 2 ช่อง (Relay 1, Relay 2)
- **Storage:** NVS Flash สำหรับบันทึกค่าตั้ง + SPIFFS สำหรับเก็บไฟล์โลโก้

### Network

- **IP Address:** กำหนดโดย DHCP อัตโนมัติ — ดูจากหน้าจอ Boot Screen หรือจาก Router
- **Protocol:** MQTT over TCP
- **Broker:** เชื่อมต่อ Mosquitto ที่ติดตั้งบน Home Assistant

## 4. Wiring & Installation / การต่อสายและติดตั้ง

### Power Connection

ต่อสายไฟ DC 6–30V เข้ากับขั้วต่อ VCC และ GND ด้านหลังอุปกรณ์ ตรวจสอบขั้ว + และ - ให้ถูกต้องก่อนจ่ายไฟ

เซ็นเซอร์ RS485 สามารถรับไฟจาก Power Supply เดียวกันได้เลย โดยต่อสาย VCC และ GND ของเซ็นเซอร์เข้ากับ Power Supply ตัวเดียวกันกับอุปกรณ์หลัก ไม่จำเป็นต้องแยก Power Supply

> **หมายเหตุ:** พอร์ต USB-C ด้านข้างใช้สำหรับ **Flash Firmware เท่านั้น** ไม่ใช่แหล่งจ่ายไฟหลัก

### Ethernet Connection

ต่อสาย RJ45 Category 5e หรือสูงกว่า เข้ากับ Switch หรือ Router ในวงเดียวกับ Home Assistant

### RS485 Sensor Wiring

| LIV24 Terminal | เซ็นเซอร์ RS485 | หมายเหตุ |
|---|---|---|
| **A (RS+)** | RS+ / A+ | สาย Data+ |
| **B (RS-)** | RS- / B- | สาย Data- |
| **GND** | GND | ต้องต่อร่วมเสมอ |
| **VCC (Power Supply)** | VCC เซ็นเซอร์ | ต่อร่วมจาก Power Supply เดียวกัน |

### LD100 Leak Detector Pinout

| ขา LD100 | ต่อกับ |
|---|---|
| Pin 1 (VCC) | VCC จาก Power Supply เดียวกัน |
| Pin 2 (GND) | GND ร่วม |
| Pin 8 (RS+) | Terminal A ของ LIV24 |
| Pin 9 (RS-) | Terminal B ของ LIV24 |

### 5.1 First Boot: Setup Screen / หน้าจอ Setup (บูตครั้งแรก)

Setup Screen จะปรากฏเมื่อบูตครั้งแรก หรือเมื่อยังไม่มีไฟล์โลโก้อยู่ในอุปกรณ์

**สิ่งที่แสดงบนหน้าจอ:**

```
┌─────────────────────────────────────────────┐
│              SETUP MODE                      │
├──────────────────────┬──────────────────────┤
│   LOGO UPLOAD        │   ADD TELEGRAM BOT   │
│                      │                      │
│   [QR Code]          │   [QR Code]          │
│   (ปรากฏหลัง IP)    │   (แสดงทันที)        │
│                      │                      │
│  "192.168.1.xx"      │  @liv24alert_bot     │
│  (Waiting for IP...) │                      │
│                      │                      │
│ Plug in Ethernet     │ Scan to receive      │
│ then scan to upload  │ alerts via Telegram  │
└──────────────────────┴──────────────────────┘
```

**คอลัมน์ซ้าย — Logo Upload:**
- QR Code จะซ่อนอยู่ตอนแรก และปรากฏขึ้นเมื่อ Ethernet เชื่อมต่อสำเร็จและได้รับ IP
- ข้อความ "Waiting for IP..." จะเปลี่ยนเป็น IP address จริง เช่น `192.168.1.117`
- Scan QR เพื่อเปิดหน้าเว็บสำหรับอัปโหลดโลโก้

**คอลัมน์ขวา — Telegram Bot:**
- QR Code แสดงทันทีและไม่เปลี่ยนแปลง
- Scan เพื่อเปิด Telegram และ Add Bot `@liv24alert_bot`
- ต้องกด **Start** ใน Telegram หลังจาก Add Bot เพื่อให้รับการแจ้งเตือนได้

### 5.2 Logo Upload via Web Browser / อัปโหลดโลโก้ผ่านเว็บ

โลโก้บริษัทจะแสดงในหัวของทุกหน้าจอหลัก การอัปโหลดทำได้ผ่าน Web Browser

**ขั้นตอนการอัปโหลดโลโก้:**

1. ต่อสาย Ethernet ให้ครบ รอจนหน้าจอแสดง IP Address
2. เปิด Web Browser บนคอมพิวเตอร์ที่อยู่ใน Network เดียวกัน
3. ไปที่ URL: `http://<IP ที่แสดงบนหน้าจอ>` เช่น `http://192.168.1.117`
4. หน้าเว็บ **LIV24 Setup** จะปรากฏขึ้น มีพื้นที่ Drag-and-Drop สำหรับไฟล์รูป
5. ลาก-วางไฟล์ภาพ (JPEG ที่แนะนำ ขนาดสี่เหลี่ยม เช่น 200×200 px) ลงในพื้นที่
6. กด **Upload** รอจนแถบแสดงสถานะเปลี่ยนเป็น "Upload successful"
7. อุปกรณ์จะ **รีสตาร์ทอัตโนมัติ** และบูตสู่หน้าจอหลักพร้อมโลโก้

> **หมายเหตุ:** โลโก้จะถูกบันทึกลง SPIFFS Flash ถาวร ไม่หายเมื่อ Reboot และไม่ต้อง Flash Firmware ใหม่

**ข้อแนะนำไฟล์โลโก้:**
- ไฟล์: JPEG (.jpg)
- ขนาดแนะนำ: สี่เหลี่ยมจัตุรัส (1:1) เช่น 200×200 หรือ 512×512
- ไฟล์ไม่ควรใหญ่เกิน 200 KB เพื่อความเร็วในการแสดงผล

### 5.3 How to Return to Setup Mode / วิธีกลับสู่หน้าจอ Setup

เมื่ออัปโหลดโลโก้แล้ว หน้าจอ Setup จะไม่ปรากฏขึ้นอีกตามปกติ ในกรณีที่ต้องการเปลี่ยนโลโก้หรือกลับสู่ Setup Mode ให้ทำดังนี้:

**วิธี: Boot-Hold Reset**

1. กดปุ่ม **BOOT** บนตัวอุปกรณ์ค้างไว้
2. ขณะที่กดค้าง ให้กด **Reset** (หรือถอด-เสียบไฟ)
3. ปล่อยปุ่ม BOOT หลังจากที่หน้าจอเริ่มแสดงผล
4. อุปกรณ์จะล้างโลโก้ที่เก็บไว้และรีสตาร์ท
5. หน้าจอ Setup จะปรากฏขึ้นพร้อมให้อัปโหลดโลโก้ใหม่

> **หมายเหตุ:** ขั้นตอนนี้จะลบโลโก้เดิมออก แต่ไม่กระทบกับค่า Sensor Model, Slave ID หรือ Calibration ที่บันทึกไว้

### 5.4 Splash Screen (Normal Boot) / หน้าจอ Splash

เมื่อมีโลโก้อยู่แล้ว อุปกรณ์จะแสดง Splash Screen ระยะสั้นประมาณ **2.5 วินาที** ก่อนเข้าสู่หน้าจอหลัก

**เนื้อหาบน Splash Screen:**
- โลโก้บริษัทขนาดใหญ่ตรงกลาง
- ชื่อ "LIV-24" และ "IoT NODE" ด้านล่าง

หลังจาก 2.5 วินาที จะ Fade เข้าสู่ **USER Screen** โดยอัตโนมัติ

> หากยังไม่มีโลโก้: Splash Screen จะแสดงแค่ข้อความ "LIV-24 IoT NODE" บนพื้นหลังดำแทน

### 5.5 Main Sensor Screen — USER Mode / หน้าจอ Sensor หลัก

USER Screen คือหน้าจอหลักที่แสดงข้อมูลเซ็นเซอร์แบบ Real-time แบ่งออกเป็น 3 Tab ตามประเภทเซ็นเซอร์

**โครงสร้างหน้าจอ:**

```
┌─────────────────────────────────────────────────────────────────┐
│ [LOGO]  LIV-24   IoT NODE  SN-300BYH-M      AQI Color [ON/OFF] │  ← Header
├─────────────────────────────────────────────────────────────────┤
│   PM 2.5    30.5 ug/m³  │  EC   148 uS/cm   │  LEAK  NORMAL   │  ← Nav Bar
│ ══════════════════════  │                   │                   │  ← Active Tab Indicator
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  [TEMPERATURE  28.5°C]     [HUMIDITY  65%]                      │
│  [PM 2.5   30.5 ug/m³]     [PM 10    50.4 ug/m³]               │
│  [SOUND LEVEL         63 dB                      ]              │
│                                                                 │
├─────────────────────────────────────────────────────────────────┤
│  DEV  EXEC                                                  [▶] │  ← Navigation
└─────────────────────────────────────────────────────────────────┘
```

#### Header Bar (แถบหัว)

- **โลโก้** (ซ้ายสุด) — แสดงเมื่อมีโลโก้อยู่ในระบบ
- **LIV-24** — ชื่ออุปกรณ์
- **IoT NODE** + ชื่อ Sensor Model ที่กำลังใช้งาน เช่น `SN-300BYH-M`
- **AQI Color Toggle** (ขวาสุด) — เปิด/ปิดการแสดงสีตามระดับ AQI บนการ์ด PM2.5 และ PM10

#### Sensor Nav Bar (แถบ Tab)

แถบนี้มี 3 Tab แสดงค่าล่าสุดแบบ Real-time ตลอดเวลา แม้จะอยู่ใน Tab อื่น:

| Tab | แสดงค่า | คลิกเพื่อ |
|---|---|---|
| **PM 2.5** | ค่า PM2.5 ล่าสุด (µg/m³) | ดูข้อมูล PM + Temp + Hum + Sound |
| **EC** | ค่า EC ล่าสุด (µS/cm) | ดูข้อมูลคุณภาพน้ำ |
| **LEAK** | สถานะ NORMAL / ALARM | ดูสถานะ Leak Detector |

Tab ที่กำลังใช้งานจะมีเส้น Cyan ขีดใต้ และค่าจะสว่างกว่า Tab อื่น

#### PM Tab — Air Quality & Environment

เมื่อกด Tab **PM 2.5** จะแสดง 5 การ์ดข้อมูลสภาพแวดล้อม:

| การ์ด | ข้อมูล | หน่วย |
|---|---|---|
| TEMPERATURE | อุณหภูมิ (Calibrated) | °C |
| HUMIDITY | ความชื้นสัมพัทธ์ (Calibrated) | % |
| PM 2.5 | ฝุ่นละอองขนาด 2.5 µm | µg/m³ |
| PM 10 | ฝุ่นละอองขนาด 10 µm | µg/m³ |
| SOUND LEVEL | ระดับเสียง | dB |

**AQI Color System:**

เมื่อเปิด AQI Color Toggle การ์ด PM2.5 และ PM10 จะเปลี่ยนสีพื้นหลังตามระดับคุณภาพอากาศ:

| สี | ช่วงค่า PM2.5 | ความหมาย |
|---|---|---|
| เขียว | ≤ 12 µg/m³ | GOOD |
| เหลือง | ≤ 35.4 µg/m³ | MODERATE |
| ส้ม | ≤ 55.4 µg/m³ | SENSITIVE |
| แดง | ≤ 150.4 µg/m³ | UNHEALTHY |
| ม่วง | ≤ 250.4 µg/m³ | VERY UNHEALTHY |
| น้ำตาลเข้ม | > 250.4 µg/m³ | HAZARDOUS |

เมื่อปิด AQI Color Toggle การ์ดจะแสดงพื้นหลังสีเข้มเหมือนกันทุกการ์ด (โหมด plain)

#### EC Tab — Water Quality

เมื่อกด Tab **EC** จะแสดงการ์ดขนาดใหญ่กลางหน้าจอ:

- **EC VALUE** — ค่า Electrical Conductivity หน่วย µS/cm (ตัวเลขขนาดใหญ่)
- **TDS** — ค่า Total Dissolved Solids หน่วย mg/L (คำนวณจาก EC × 0.5)

ตัวอย่าง: EC = 148 µS/cm → TDS = 74 mg/L

#### LEAK Tab — Leak Detector

เมื่อกด Tab **LEAK** จะแสดงการ์ดขนาดใหญ่กลางหน้าจอ:

- **NORMAL** — ไม่พบน้ำรั่ว (พื้นหลังสีเขียวเข้ม)
- **ALARM** — ตรวจพบน้ำรั่ว (พื้นหลังเปลี่ยนเป็นสีแดงเข้ม)

ค่าใน Nav Bar ด้านบนก็จะเปลี่ยนสีตาม: NORMAL = เขียว, ALARM = แดง

### 5.6 Air Quality History Screen — PM Mode / หน้าจอประวัติคุณภาพอากาศ

PM Screen แสดงค่าเซ็นเซอร์ปัจจุบันพร้อมประวัติย้อนหลัง 24 ชั่วโมง

**โครงสร้างหน้าจอ:**

```
┌─────────────────────────────────────────────────────────────────┐
│ [LOGO]  AIR QUALITY                                             │  ← Header
├──────┬──────┬──────┬──────┬──────────────────────────────────-──┤
│PM2.5 │ PM10 │ TEMP │  HUM │ SOUND                               │  ← Tab Bar
└──────┴──────┴──────┴──────┴────────────────────────────────────-┘
│                        PM 2.5                                   │
│                         30.5                                    │  ← Current Value
│                        ug/m³                                    │
│                       MODERATE                                  │  ← Status Label
├─────────────────────────────────────────────────────────────────┤
│  PM 2.5 | 24H HISTORY                                           │
│ ┌────┬────┬────┬────┬────┬ ... ┬────┐                           │
│ │-22h│-21h│-20h│    │    │     │Now │   ← 24 cards              │
│ │ ●  │ ●  │ ●  │ ●  │    │     │ ●  │   ← Color dots            │
│ │ 28 │ 31 │ 29 │    │    │     │ 30 │   ← Values                 │
│ └────┴────┴────┴────┴────┴─────┴────┘   ← Scrollable →         │
│                                                             [▶] │
└─────────────────────────────────────────────────────────────────┘
```

#### Tab Bar (5 Tabs)

แตะ Tab เพื่อดูข้อมูลและประวัติของแต่ละตัวแปร:

| Tab | ข้อมูล | Status Labels |
|---|---|---|
| **PM2.5** | PM 2.5 µg/m³ | GOOD / MODERATE / SENSITIVE / UNHEALTHY / VERY UNHEALTHY |
| **PM10** | PM 10 µg/m³ | GOOD / MODERATE / SENSITIVE / UNHEALTHY |
| **TEMP** | อุณหภูมิ °C | COLD / COOL / COMFORTABLE / WARM / HOT / VERY HOT |
| **HUM** | ความชื้น % | DRY / COMFORTABLE / HUMID / VERY HUMID |
| **SOUND** | ระดับเสียง dB | QUIET / MODERATE / LOUD / HARMFUL |

#### Current Value Block (กลางหน้าจอ)

- แสดงชื่อ + ค่าปัจจุบัน + หน่วย + Status Label
- สีของค่าและ Status Label จะเปลี่ยนตามระดับ — เช่น เขียว = ปกติ, แดง = อันตราย

#### 24H History Strip (แถบล่าง)

แถบด้านล่างแสดง **24 การ์ดย่อย** (1 การ์ด = 1 ชั่วโมงที่ผ่านมา) เรียงจากซ้ายไปขวา:

- **ซ้ายสุด** = ข้อมูล 23 ชั่วโมงที่แล้ว
- **ขวาสุด** = ข้อมูลชั่วโมงปัจจุบัน (แสดงว่า "Now" สีฟ้า)

**เนื้อหาในแต่ละการ์ด:**
- **เวลา** — ชั่วโมง เช่น `14:00`, `15:00`, ... หรือ `Now` สำหรับชั่วโมงล่าสุด
- **จุดสี (Color Dot)** — วงกลมสีที่แสดงระดับคุณภาพตาม AQI/Status ณ ชั่วโมงนั้น
- **ค่า** — ค่าเฉลี่ยของชั่วโมงนั้น

การ์ดที่ยังไม่มีข้อมูล (ชั่วโมงก่อนหน้าที่อุปกรณ์ยังไม่เปิด) จะแสดง `--` และจุดสีเทา

> **ข้อมูล 24 ชั่วโมง** ถูกส่งมาจาก Home Assistant ผ่าน MQTT ทุก 1 ชั่วโมง ระบบจึงต้องเชื่อมต่อกับ HA จึงจะมีประวัติ

สามารถ **Scroll ซ้าย-ขวา** ในแถบนี้ได้เมื่อมีข้อมูลมากกว่าความกว้างหน้าจอ

### 5.9 DEV Mode — Sensor Calibration / โหมด DEV — ปรับเทียบเซ็นเซอร์

DEV Mode ใช้สำหรับปรับค่า Calibration ของเซ็นเซอร์แต่ละตัวโดยไม่ต้อง Flash Firmware ใหม่

**วิธีเข้าถึง:** แตะปุ่ม **DEV** ที่มุมล่างซ้ายของ USER Screen

**โครงสร้างหน้าจอ:**

```
┌─────────────────────────────────────────────────────────────────┐
│ DEV MODE                                           [← USER]     │
├─────────────────────────────────────────────────────────────────┤
│  TEMPERATURE    RAW: 24.2        >        CAL: 23.7 °C         │
│  OFF  [−]  [+0.00]  [+]      GAIN  [−]  [1.00]  [+]           │
├─────────────────────────────────────────────────────────────────┤
│  HUMIDITY       RAW: 66.0        >        CAL: 65.2 %          │
│  OFF  [−]  [+0.00]  [+]      GAIN  [−]  [1.00]  [+]           │
├─────────────────────────────────────────────────────────────────┤
│  SOUND          RAW: 63.0        >        CAL: 63.0 dB         │
│  OFF  [−]  [+0.00]  [+]      GAIN  [−]  [1.00]  [+]           │
├─────────────────────────────────────────────────────────────────┤
│  PM 2.5         RAW: 30.0        >        CAL: 30.0 ug/m3      │
│  OFF  [−]  [+0.00]  [+]      GAIN  [−]  [1.00]  [+]           │
├─────────────────────────────────────────────────────────────────┤
│  PM 10          RAW: 50.0        >        CAL: 50.0 ug/m3      │
│  OFF  [−]  [+0.00]  [+]      GAIN  [−]  [1.00]  [+]           │
├─────────────────────────────────────────────────────────────────┤
│  [ SAVE TO NVS ]                                 saved / unsaved │
└─────────────────────────────────────────────────────────────────┘
```

**การ์ดแต่ละเซ็นเซอร์แสดง:**

- **RAW** (สีเทา) — ค่าดิบที่อ่านมาจากเซ็นเซอร์โดยตรง อัปเดตทุก 2 วินาที
- **CAL** (สีฟ้า Cyan) — ค่าหลัง Calibration ที่จะถูกใช้งานจริงและส่งไป MQTT

**สูตร Calibration:**

```
CAL = RAW × GAIN + OFFSET
```

- **OFFSET** — ปรับได้ทีละ ±0.1 (Temp/Hum/PM) หรือ ±1.0 (Sound) ช่วง -50 ถึง +50
- **GAIN** — ปรับได้ทีละ ±0.01 ช่วง 0.10 ถึง 5.00

**ตัวอย่าง:** ถ้า Temp อ่านได้ 24.2°C แต่จริงๆ ควรเป็น 23.7°C → ตั้ง OFFSET = -0.5

**การบันทึก:**

- กด **SAVE TO NVS** เพื่อบันทึกลง Flash ถาวร
- สถานะแสดง "unsaved" (ส้ม) เมื่อมีการเปลี่ยนแต่ยังไม่บันทึก
- สถานะเปลี่ยนเป็น "saved" (เขียว) เมื่อบันทึกสำเร็จ
- ค่า Calibration จะคงอยู่แม้รีสตาร์ทอุปกรณ์

> ถ้าเลื่อนออกจาก DEV Mode โดยไม่กด Save ค่าที่ปรับจะหายไปเมื่อ Reboot

### 5.10 EXEC Mode — KPI Overview / โหมด EXEC — ภาพรวม KPI

EXEC Mode ออกแบบสำหรับผู้บริหารหรือผู้ดูแลอาคาร แสดงค่า KPI สิ่งแวดล้อมแบบ Dashboard พร้อมกราฟประวัติ 7 วัน

**วิธีเข้าถึง:** แตะปุ่ม **EXEC** ที่มุมล่างซ้ายของ USER Screen

**โครงสร้างหน้าจอ:**

```
┌─────────────────────────────────────────────────────────────────┐
│ KPI OVERVIEW                                       [← USER]    │
├──────────────────────────┬──────────────────────────────────────┤
│  TEMPERATURE             │  HUMIDITY                            │
│       28.5               │       65.2                           │
│        °C                │        %                             │
│  7D HISTORY              │  7D HISTORY                          │
│  ▁▂▃▄▂▃▄                │  ▃▃▃▄▄▃▄                            │
├──────────────────────────┼──────────────────────────────────────┤
│  PM 2.5                  │  PM 10                               │
│       30.5               │       50.4                           │
│       ug/m3              │       ug/m3                          │
│  7D HISTORY              │  7D HISTORY                          │
│  ▁▁▂▁▁▃▂                │  ▂▂▁▂▁▂▃                            │
└──────────────────────────┴──────────────────────────────────────┘
```

**4 KPI Cards ในรูปแบบ 2×2:**

| การ์ด | ข้อมูล | ช่วงสี |
|---|---|---|
| TEMPERATURE | อุณหภูมิ °C | น้ำเงิน (เย็น) → เขียว (สบาย) → แดง (ร้อน) |
| HUMIDITY | ความชื้น % | เหลือง (แห้ง) → เขียว (สบาย) → น้ำเงิน (ชื้น) |
| PM 2.5 | ฝุ่น µg/m³ | เขียว → เหลือง → แดง (ตาม AQI) |
| PM 10 | ฝุ่น µg/m³ | เขียว → เหลือง → แดง (ตาม AQI) |

**กราฟ 7D History:**

แต่ละการ์ดมีกราฟแท่ง 7 แท่ง (bar chart) แสดงค่าเฉลี่ยรายวันย้อนหลัง 7 วัน:
- แท่งซ้ายสุด = 7 วันที่แล้ว, แท่งขวาสุด = วันล่าสุด
- สีแท่งตรงกับค่า KPI ณ วันนั้น
- ความสูงแท่งเป็น proportional กับ max range ของแต่ละค่า

> ข้อมูล 7 วันส่งมาจาก Home Assistant ผ่าน MQTT คล้ายกับ 24H History

## 7. Sensor Operation / การทำงานของเซ็นเซอร์

### รอบการอ่านค่า

อุปกรณ์อ่านค่าจากเซ็นเซอร์ทุก **2 วินาที** ผ่าน Modbus RTU RS485 และส่งข้อมูลไปยัง MQTT Broker ทันที

### MQTT Topics

| Topic | ทิศทาง | เนื้อหา |
|---|---|---|
| `liv24/sensors` | Publish | ข้อมูล Sensor ทั้งหมด (ทุก 2 วินาที) |
| `liv24/relay/1/set` | Subscribe | ควบคุม Relay 1 (payload: `ON` หรือ `OFF`) |
| `liv24/relay/2/set` | Subscribe | ควบคุม Relay 2 (payload: `ON` หรือ `OFF`) |
| `liv24/relay/1/state` | Publish | สถานะ Relay 1 ปัจจุบัน |
| `liv24/relay/2/state` | Publish | สถานะ Relay 2 ปัจจุบัน |

### ตัวอย่าง Payload

**SN-300BYH-M (PM Sensor)**
```
{"temp":28.5,"hum":65.2,"pm25":30.5,"pm10":50.4,"sound":63.8}
```

**CWT-EC/TDS**
```
{"ec":148.0}
```

**LD100-LEAK**
```
{"leak":false}
```

### EC Water Quality Reference

| ช่วงค่า (µS/cm) | คุณภาพน้ำ |
|---|---|
| < 50 | น้ำกลั่น / RO |
| 50 – 200 | น้ำกรองสะอาด |
| 200 – 500 | น้ำประปา (ปกติ) |
| 500 – 1,000 | น้ำแร่ |
| 1,000 – 3,000 | น้ำคุณภาพต่ำ |
| > 3,000 | น้ำเสีย / ปนเปื้อน |

## 9. Troubleshooting / การแก้ไขปัญหาเบื้องต้น

### หน้าจอไม่แสดงผล

- ตรวจสอบการต่อสาย VCC และ GND จาก Power Supply ให้แน่ใจว่าขั้วถูกต้องและแรงดันอยู่ในช่วง 6–30V
- กด Reset Button ที่ด้านข้างอุปกรณ์

### Sensor อ่านค่าไม่ได้ / แสดง 0.00 หรือ --

- ตรวจสอบสาย RS485: A ต่อ A+, B ต่อ B-, GND ต่อ GND
- ตรวจสอบ Slave ID ใน Web Config ให้ตรงกับที่ตั้งในเซ็นเซอร์
- ตรวจสอบไฟเลี้ยงเซ็นเซอร์จาก Power Supply
- กด **Test Connection** ใน Web UI
- เข้า DEV Mode เพื่อดูค่า RAW vs CAL ว่าอ่านค่าได้หรือไม่

### ไม่เชื่อมต่อ Network

- ตรวจสอบสาย RJ45 และ LED ที่ Port Ethernet
- ตรวจสอบ IP ของอุปกรณ์จากหน้าจอ Boot Screen และตรวจสอบว่าไม่ซ้ำกับอุปกรณ์อื่นใน Network
- ตรวจสอบ Subnet: อุปกรณ์และ Home Assistant ต้องอยู่ใน Subnet เดียวกัน

### ไม่รับ Telegram Alert

- ตรวจสอบว่ากด **Start** กับ Bot แล้ว
- ตรวจสอบ Home Assistant Automation ว่า Active อยู่
- ตรวจสอบว่า HA เชื่อมต่อกับ MQTT Broker ได้

### 24H History ไม่แสดงข้อมูล

- ข้อมูลประวัติส่งมาจาก Home Assistant ทุก 1 ชั่วโมง ต้องรอให้ครบรอบก่อน
- ตรวจสอบว่า HA Automation `LIV24 Hourly History Update` ทำงานอยู่
- ข้อมูลจะปรากฏเต็ม 24 ชั่วโมงหลังจากอุปกรณ์ทำงานครบ 24 ชั่วโมง

### ต้องการเปลี่ยนโลโก้

- ดูหัวข้อ 5.3 — ใช้ Boot-Hold Reset เพื่อล้างโลโก้เดิมและกลับสู่ Setup Mode
